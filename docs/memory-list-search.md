Use bounded SQL summaries and EXISTS source queries rather than fetching every memory's full history on each list request. Search only this memory's authorized displayed source fields: original/current title/clarification, owned revisions, applied debrief/closing changes for this ID, owned valid class entries for this note, approved owner contributions and context/tags. No proposals, foreign/staged media, global multi-note class text, access/queues/publications or inferred teacher authorship. Search terms are bound literal substrings; no SQL LIKE wildcard interpretation. SQL case folding covers English/Shqip and common Spanish accented capitals, without changing originals.

History filters are independent facts, not stages/mastery: without debrief, with approved debrief, class work, explicit user/AI/tutor contributions. Several may be selected; selected history conditions combine with OR, then AND with language/query. A memory can display multiple facts. Unknown historical provenance remains unknown. Dates are shown only when the source records one; no fabricated event date.

Capture reuses the existing Workspace form/state/persistence/upload services through a narrow adapter; opening it must not start recording. Existing draft language/content/media survive list navigation and filters. Only a new empty draft adopts selected language. After successful capture, refresh current list. Legacy routes remain supported; this delivery does not redesign their other screens.

Acceptance: synthetic D1/R2 owner and cross-note isolation, pending exclusion, combined/overlapping filters, literal query escaping, accented case, paging, no duplicate memories and no read side effects; old MCP/notes stay exact. Client abort/stale/typing/page/error/retry behavior, semantic links/focus/live status, empty/loading/interrupted states, keyboard and emulated touch in isolated Chrome. ## Implementation and verification

- The collection query materializes small source groups and aggregates each note once, returning at most 20 summaries plus a next-page offset. The actual D1 emulator rejected seven flat UNION arms; groups of at most three fixed the observed parser limit without per-note requests, temporary persisted tables or schema changes. Literal substring folding covers the documented letters; this is not fuzzy/OCR/audio-transcript search.
- The client tags every state with its semantic filter key, immediately hides mismatched results, debounces typing, aborts superseded reads and deduplicates appended pages. Chrome caught a transient previous-language render before a React effect; the filter-key guard fixed it. Network failures retain only explicitly labeled results for the same query; authentication/invalid-contract failures clear them.
- The shared navigation reuses the exact logo at effective 100x50. The flexible main area scrolls without overlaying the persistent capture footer. History checkboxes combine by union, not mutually exclusive stages. These facts do not change legacy reviewed/worked or tutor eligibility.
- Capture uses the original form, media upload/storage services and optional tags. Browsing another language does not rewrite an existing draft; text/photo/context tags survive reload. Only an empty draft adopts the selected language. The page keys the Workspace by authenticated user so a different session cannot inherit the prior component state. No microphone or hardware camera is started by opening capture.
- Built-Worker integration passed 71 assertions: owner/cross-note/pending/global-class-source isolation, all text/context/history sources, literal query characters, accented case, overlapping filters, paging, old DTO/MCP compatibility, all-table read side-effect comparison, DOM states and asset serving. Client unit tests cover debounce, cancellation, stale completions, paging/deduplication and failures.
- Actual isolated Chrome passed 38 assertions at mobile 390 px and desktop 1280 px: hydration, geometry, design font loaded, keyboard/skip focus, trusted emulated taps, combined histories, query restoration through browser Back, empty/error/interrupted/retry states, and existing synthetic capture with text/photo/tags and original draft language through browsing/reload. Only the intended POST /api/uploads and /api/notes were issued. This is not physical-iPhone, hardware camera/microphone or screen-reader certification. Screenshots and raw QA reports stay ignored under .sites-runtime/memory-list/.

That preview's capture uses temporary synthetic data, not production.
